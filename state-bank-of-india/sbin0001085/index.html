How the code SBIN0001085 is built

SBIN is the bank part: the letters of State Bank of India. The fifth character is always the digit 0. 001085 is the part that names this branch.

The MICR code 767002102 is the number printed along the bottom of this branch's cheques. 767 is the city (the same three digits that begin the PIN code 767017), 002 is the bank and 102 is the branch.
