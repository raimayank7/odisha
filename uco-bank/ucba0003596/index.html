How the code UCBA0003596 is built

UCBA is the bank part: the letters of UCO Bank. The fifth character is always the digit 0. 003596 is the part that names this branch.

The MICR code 753028012 is the number printed along the bottom of this branch's cheques. 753 is the city (the same three digits that begin the PIN code 753008), 028 is the bank and 012 is the branch.
